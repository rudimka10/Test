# Infection Shot — прототип (Zenject + MVC)

Всё лежит в `Assets/InfectionShot`, сцена `Assets/InfectionShot/Scenes/Main.unity`.

## Механика (как в ТЗ)
- Шар-игрок в левом нижнем углу, дверь в правом верхнем, на дорожке препятствия.
- Зажать шар: от него отделяется выстрел и растёт, шар-игрок уменьшается на столько же. Чем дольше держишь, тем больше выстрел.
- Отпустить: выстрел летит к двери, на первом препятствии «заражает» всех в радиусе (зависит от размера выстрела), они взрываются.
- Когда зона расчищена, шар-игрок прыжками идёт вперёд по центру дорожки. Дорожка сужается вместе с шаром.
- Дверь открывается, когда шар ближе 5 м.
- Проигрыш: «Overcharged» (отдал слишком много, достигнут критический размер) или «Not enough mass» (оставшейся массы не хватит, чтобы расчистить путь).
- Запас 20%: плановая стоимость расчистки не больше 80% тратимой массы. Генератор сцены считает это и падает с ошибкой, если уровень нарушает запас.

## Запуск
1. `Tools > Infection Shot > Rebuild Scene` пересобирает сцену и ассеты с нуля.
2. Открыть `Assets/InfectionShot/Scenes/Main.unity` и нажать Play. Мышь заменяет касание, нажимать нужно на шар-игрок.

## Структура (MVC)
```
Config/       GameConfig: все числа баланса в одном ScriptableObject
Models/       чистая логика без сцены: GameModel, FieldModel, ObstacleModel, PathModel, DoorModel, ShotMath
Controllers/  связывают модель и вид: Charge, Shot, Path, Player, Game, Hud
Views/        только отображение: PlayerView, ShotView, ObstacleView, FieldView, LaneView, DoorView, FxView, HudView, PointerInputView
Installers/   GameInstaller: единственное место, где собирается Zenject-граф
Editor/       SceneBuilder: генератор сцены
```
Один asmdef на игру (`InfectionShot`) и один для редактора. Zenject используется только для внедрения зависимостей (SceneContext + MonoInstaller), контроллеры реализуют `IInitializable` / `ITickable` / `IDisposable`.

## Что проверено (в Editor через MCP)
- Проект компилируется без ошибок и предупреждений, сцена собирается, аудит запаса проходит.
- Сквозной прогон автопилотом (замедленное время, плановые выстрелы, ДО ребаланса): 4 выстрела (0.045, 0.221, 0.035, 0.330), дверь открылась на дистанции 5 м, состояние Won, экран «You win!», масса в конце 0.339 при критической 0.2.
- Баланс (после усложнения): минимальный выстрел 0.07, радиус заражения 0.45 + 3.8·масса, кластеры чуть реже. Расчёт по сцене: оптимальный план ≈0.465 из 0.8 доступной массы (резерв выше 20%), «спам минимальных тапов» ≈0.49 (7 выстрелов; раньше ≈0.25). Это расчёт моделью, автопилотом после ребаланса не прогонялось.
- Overcharged: удержание без отпускания приводит к Lost с панелью «Overcharged» (масса 0.195).
- Restart: масса 1, позиция 0, все 364 препятствия возвращены, дверь закрыта.
- «Not enough mass»: сработало в первом прогоне, когда перелитые выстрелы не оставили массы на последнюю группу.
- Кадры камеры (PNG из Editor) сверены со скриншотом из ТЗ: поле зелёных капсул, серая сетка, розовая дорожка, оранжевый шар и дверь.
